# Chat preview

This branch adds a React practice app under `preview/`. It is the version shown in chat.

It does not replace `feat/practice-mvp` ([PR #1](https://github.com/zarmih/supacon/pull/1)). Do not merge this branch over that pull request.

The record stays on the device (`localStorage`, key `supacon.preview.v1`). There is no account. Language is English or Russian. The page cannot stand in front of another app.

`preview/` is the practice source (logic, copy, screens). It is not a standalone install. The Vite PWA remains on `feat/practice-mvp`.
